# Новита: демо нового сайта

Статический демо-сайт для показа заказчику. Без сборки и сервера: открывается как обычный сайт, всё состояние хранится в браузере.

## Как запустить

```bash
cd demo
python3 -m http.server 8000
# открыть http://localhost:8000
```

Можно открыть `index.html` двойным щелчком или опубликовать через GitHub Pages (Settings, Pages, ветка `main`, папка `/root`).

## Что показать

Внизу слева плашка «ДЕМО: смотреть сайт как» переключает роль сотрудника.

| Роль | Что видит |
|---|---|
| Посетитель | Обычный сайт: главная, каталог, карточка товара, блог |
| Редактор статей | Только статьи. Пишет текст, выбирает «Сайт» и «Telegram», публикует |
| Менеджер каталога | Только товары. В карточке включает «Режим правки» и меняет цену, название, описание, характеристики прямо на странице |
| Администратор | Всё: товары, статьи, пользователи и роли, подключения (Ozon, Telegram, оплата) |

Выбор цвета зависит от товара: у кроватей это «Цвет металла», у диванов «Цвет обивки» или «Цвет боковин», у механизмов и оснований цвета нет. У «Страйп 1н» есть реальные фото в чёрном и белом, при смене цвета меняется вся галерея. Где фото в нужном цвете пока нет, сайт пишет об этом в подписи к фото.

Главное для показа: открыть **Страйп 1н**, включить роль «Менеджер каталога», нажать «Режим правки», поменять цену и нажать «Сохранить».

Прямые ссылки для показа:

- `?role=catalog&edit=1#/p/strajp-1n` открывает карточку сразу в режиме правки
- `?role=editor#/blog` открывает блог как редактор
- `?role=admin#/admin/users` открывает управление ролями

## Данные

- Фото и названия моделей взяты с metallstil.ru.
- Реальные цены и характеристики есть только у «Страйп 1н». У остальных товаров цены условные, на них стоит пометка «демо-цена».
- Статьи блога сокращены, тексты написаны для демо.
- Ozon, Telegram и оплата показаны как макет. Реальной отправки нет.
- Кнопка «Сбросить» очищает все правки.
