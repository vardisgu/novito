# Новита: демо нового сайта

Статический демо-сайт для показа заказчику. Без сборки и сервера: открывается как обычный сайт, всё состояние хранится в браузере. Оформление взято с текущего сайта фабрики: логотип, синяя палитра, шрифты Montserrat и Inter.

## Как запустить

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Для покупателей

Публичный сайт: главная, каталог, карточка товара, блог, контакты. Покупатель выбирает размер и цвет, нажимает «Купить», заполняет форму (контакты, доставка или самовывоз, способ оплаты), оплачивает на странице банка (имитация) и получает заказ с номером. Входа для сотрудников на публичном сайте нет.

Выбор цвета зависит от товара: у кроватей это «Цвет металла», у диванов «Цвет обивки» или «Цвет боковин», у механизмов и оснований цвета нет. У «Страйп 1н» есть реальные фото в чёрном и белом, при смене цвета меняется вся галерея.

## Для сотрудников: адрес /admin

Вход по адресу `/admin` (в демо `#/admin`, также работает `admin/`). Админка зависит от почты. Пароль у всех демо-почт: `novita`.

| Почта | Роль | Что видит |
|---|---|---|
| `redactor@novita.demo` | Редактор статей | Только статьи: список, правка, публикация на сайт и в Telegram |
| `catalog@novita.demo` | Менеджер каталога | Товары (правка прямо в карточке) и заказы со сменой статуса |
| `admin@novita.demo` | Администратор | Всё, плюс пользователи (добавить и удалить сотрудника) и подключения |

Главное для показа:

1. Открыть сайт как покупатель, купить «Страйп 1н» и дойти до номера заказа.
2. Открыть `/admin`, войти как `catalog@novita.demo`, увидеть новый заказ и сменить его статус.
3. Открыть карточку «Страйп 1н», нажать «Режим правки», поменять цену, сохранить.
4. Выйти и войти как `redactor@novita.demo`, чтобы показать другую админку.

Ссылки для показа: `?role=catalog&edit=1#/p/strajp-1n` открывает карточку в режиме правки, `?role=admin#/admin/users` открывает управление пользователями.

Все аккаунты только для демо. В настоящем проекте пароль и права проверяет сервер, а сотрудников создаёт и удаляет администратор.

## Данные

- Фото и названия моделей взяты с metallstil.ru.
- Реальные цены и характеристики есть только у «Страйп 1н». У остальных товаров цены условные, на них стоит пометка «демо-цена».
- Заказы в списке для примера условные. Ozon, Telegram и оплата показаны как макет, реальной отправки нет.

```
js/app.js       маршруты, корзина, оплата, кабинет

```
